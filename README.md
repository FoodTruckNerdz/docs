# Documentation

This repository contains extended documentation in any number of formats. Before consulting these docs, see the following to start developing with FoodTruckNerdz:

FoodTruckNerds [GitHub Profile](<https://www.github.com/FoodTruckNerds/>).

The `obsidian` folder is an Obsidian notebook. We will be moving away from Obsidian, due to its proprietary nature. We are aiming to use a documentation framework that uses Markdown files to produce a static doc websites.

I have chosen to use Fumadocs <https://fumadocs.dev/>.

Alternatives:

- Nextra - <https://nextra.site/> - great option
- Starlight (similar to Astro but for React and Tailwind).
- Docusaurus

## Setup

To get started editing the docs see `fumadoc-site`'s [README.md](<fumadocs-site/README.md>)
