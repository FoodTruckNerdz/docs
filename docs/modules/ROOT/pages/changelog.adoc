= Changelog
:description: Reader-facing history of FoodTruckNerdz documentation hub changes

== 2026-10-09 -- Facto stack supplies shared Antora extensions

Lunr, page-edit, build-stack, unversioned component URLs, official npm `asciidoctor-emoji`, and interim `@antora-supplemental/asciidoctor-emoji-literals` (pasted Unicode emoji → Twemoji) now come in with `@antora-supplemental/facto-stack` instead of separate package pins. The playbook still names those extensions. This site keeps `short_circuit_single: false`, so a component with one numbered version still shows a version chooser.

== 2026-10-06 -- Wide tables scroll inside the article

Variable-reference tables and other wide AsciiDoc tables stay in the middle column.
The page wraps each table and scrolls it sideways, so the contents list on the right is no longer covered.

== 2026-10-06 -- Diagram toolchain on Mermaid CLI 12 and Node.js 24

The seven documentation diagrams are rebuilt with `@mermaid-js/mermaid-cli` 12
(Puppeteer 25) on Node.js 24. The build pins Mermaid 12 to the previous dagre
layout, classic look, and 200px label wrapping, so the diagrams keep their
existing appearance in light and dark mode.

The GitHub Actions guides, action reference, and complete-workflow diagram
now show the Node.js 24 action majors the build uses (`actions/checkout@v7`,
`actions/setup-node@v7`, `actions/configure-pages@v6`, `pnpm/action-setup@v6`,
`actions/upload-pages-artifact@v5`, `actions/deploy-pages@v5`).

== 2026-09-10 -- Publish robots.txt with sitemap

* Antora `site.robots` now emits `/robots.txt` with an absolute `Sitemap:` line for the production host.

== 2026-09-10 -- Host diagram fills follow dark mode

Mermaid host SVGs now rewrite inline `fill`/`stroke` `!important` paints to
`var(--themed-svg-ftn-diagram-…)` so Valentus dark mode can recolor nodes after
the Themed SVG runtime upgrade. Diagram builds pin local `@dev-centr/themed-svg`
0.2.2 for the transform.

See xref:changelog-details/2026-09-10--host-diagram-css-vars.adoc[details].

== 2026-09-08 -- Adaptive documentation diagrams

Seven build and troubleshooting diagrams now ship as editable Mermaid source, portable light/dark SVGs, and host-themed SVGs. The Antora hub progressively applies the current Valentus theme while retaining the adaptive image fallback.

See xref:changelog-details/2026-09-08--adaptive-documentation-diagrams.adoc[details].
