== How to Capture Screenshots

=== Recommended Tools

* **Windows**: Snipping Tool (Win+Shift+S) or ShareX
* **macOS**: Screenshot (Cmd+Shift+4) or CleanShot X
* **Browser**: Built-in DevTools screenshot (Ctrl+Shift+P → "Capture screenshot")

=== Guidelines

. **Resolution**: Capture at 2x resolution if possible (retina/HiDPI displays)
. **Format**: PNG for screenshots with UI elements, SVG for diagrams
. **Dimensions**: Aim for 800-1200px width
. **Annotations**: Use red boxes/arrows sparingly to highlight key areas
. **Privacy**: Blur/redact any sensitive information (tokens, personal data)

=== File Naming Convention

----
{topic}-{specific-element}-{optional-number}.png

Examples:
  pat-creation-permissions.png
  repo-secrets-add-dialog.png
  actions-workflow-success.png
  error-start-path-logs.png
----
